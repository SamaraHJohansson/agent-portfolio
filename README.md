# Agent Portfolio
 
A collection of AI agents designed and built by Samara H. Johansson to explore how artificial intelligence can augment marketing, sales, content strategy, search visibility, and business decision-making.
 
Each agent in this portfolio was created to solve a real-world business problem. They are not chatbot demos or technical experiments for their own sake. Every build has a practical purpose, a defined workflow, and a measurable outcome.
 
The projects demonstrate a core belief:
 
**The future belongs to people who can combine strategic thinking with AI execution.**
 
The technology matters. The prompts matter. The workflows matter.
 
But strategy still comes first.
 
## Agents
 
### Content Agent
 
Transforms a single topic into a complete content package including research, content strategy, an SEO-optimised blog post, LinkedIn variations, and editorial review.
 
### Sales Relevance Agent
 
Generates relevance-first prospect intelligence and outreach by analysing the prospect's situation, pressures, priorities, and competitive context before creating communication.
 
### Search Visibility Agent
 
Evaluates a website's readiness for both traditional search engines and emerging AI search platforms by combining technical SEO analysis with Answer Engine Optimisation (AEO) and Generative Engine Optimisation (GEO) assessments.
 
## Why This Portfolio Exists
 
These projects document my journey from AI user to AI builder.
 
Each agent explores a different business function while answering the same underlying question:
 
**What happens when strategic expertise is combined with well-designed AI systems?**
 
The result is not the replacement of human judgement.
 
The result is the amplification of it.
 
## A Note on Accessibility
 
In their current form, these agents require Python, a code editor, and API credentials to run. They are built for technically curious users who are comfortable working in a development environment.
